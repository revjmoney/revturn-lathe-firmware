# Security

REVTURN runs a lathe: treat its network like the machine's control panel. Keep the ESP32 on your own network or its
own hotspot, never on the internet, and set the WebUI / hotspot passwords.

Report security problems privately: **Security**, **Report a vulnerability**
(https://github.com/revjmoney/revturn-lathe-firmware/security/advisories/new), not in a public issue.

In place: Dependabot alerts and security updates, secret scanning with push protection, CodeQL, and CI on every push
(the lathe firmware build, the screen's tests, a private-data guard).
