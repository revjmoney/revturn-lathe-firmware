# Files for the lathe's flash file system

Upload both to the root (`/`) of the lathe's flash file system (WebUI, Files panel, "Flash"):

- `preferences.json`: settings for the stock WebUI v3. Adds a **LATHE** tab to the WebUI's top bar, and stops the
  "preferences.json 404" toast the WebUI shows when the file is missing.
- `golathe.html`: what the LATHE tab shows, one big **OPEN LATHE SCREEN** button that goes to `/lathe.html`.

The lathe screen has a **WEBUI** button (top right) for the way back.

Part of REVTURN, by the maker of **[RotatoCAM](https://rotatocam.com)**.
